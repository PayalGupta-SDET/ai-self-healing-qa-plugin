AI-Powered Self-Healing QA Plugin

**Project Overview**

This project demonstrates a QA automation plugin designed to improve locator resilience and simplify test failure analysis.

**Key Features**
Locator Identification: Scans webpage elements and generates CSS/XPath locators.
Manual Element Selection: Allows a tester to select a webpage element and retrieve its locator.
Locator Healing: Explores fallback locators when the primary locator is no longer valid.
TestRail Integration: Retrieves failed test results for analysis.
Failure Analytics: Identifies recurring failure patterns and provides insights.
AI-Based Recommendations: Suggests suitable locators and explains the reasoning behind recommendations.

**Technology Stack**
JavaScript
HTML and CSS
Chrome Extension APIs
